PROJECT HIGHLIGHTS

项目亮点

六大核心特性，融合传统工艺与前沿交互技术

🤖
01
AI 手势识别
基于 MediaPipe HandLandmarker，实时追踪 21 个手部关键点。捏合落针、张开清空，手势自然流畅，延迟极低。
🎨
02
纹样路径提取
从刺绣图片像素中自动提取纹样轮廓，蛇形扫描生成缝制路径，针随图案走而非随机飘移。
🪡
03
四大传统针法
平针、回针、锁链针、十字针，每种针法独立渲染形态，长短变化自然，绣线沿路径方向旋转。
🌸
04
成品图渐显
随着针数增加，真实刺绣成品图从绣布中逐渐浮现，沉浸感十足，与针迹融合渲染，层次丰富。
🎭
05
东方美学设计
暗金色调，宋体排版，绣框绷子，织物纹理网格，完整还原传统刺绣工坊的视觉意境。
📱
06
纯前端 · 零依赖部署
单文件 HTML，无需服务端，CDN 按需加载 MediaPipe，GitHub Pages 即可访问，兼容桌面和移动端。

TECH STACK

技术架构

纯浏览器原生技术，零构建工具，最大化兼容性与可访问性

🖼️
Canvas 2D API
渲染引擎
60fps 实时渲染，绣布纹理、针迹形态、成品图渐显均在 Canvas 上完成，无 WebGL 依赖。
🤖
MediaPipe Tasks Vision
手势识别
@mediapipe/tasks-vision@0.10.18，HandLandmarker 模型，VIDEO 模式逐帧检测，GPU/CPU 自动降级。
📐
像素分析算法
路径提取
OffscreenCanvas 采样图片像素，严格阈值过滤背景，8邻域去噪，蛇形扫描排序，生成真实缝制路径。
🎨
HSL 颜色处理
线色提取
从图片像素提取颜色，RGB→HSL 加深处理，按色相区域（红/橙/黄/绿/蓝/紫）分别调整饱和度与亮度。
⌨️
多模态输入
交互系统
键盘（E绣针/R清空/1-4切换/空格摄像头）、鼠标点击、摄像头手势三种输入并行，随时切换。
🌐
GitHub Pages
部署
单仓库静态部署，HTTPS 自动启用，push 即发布，全球 CDN 加速，访问无需任何后端。

STITCH TECHNIQUES

四大针法

中国传统刺绣的四种经典针法，各有特色，键盘 1-4 快速切换

平针绣
RUNNING STITCH
最基础的针法，线条排列整齐均匀，针脚长短一致，边缘光滑整齐
回针绣
BACK STITCH
每针向后倒退半步，线迹紧密连续，如缝纫机走线般结实
锁链针
CHAIN STITCH
绣线在针下绕圈后抽出，形成环环相扣的锁链效果，装饰性强
十字针
CROSS STITCH
两针交叉成"十"字形，常用于几何纹样与文字图案
